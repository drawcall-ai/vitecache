Load the model once. Ship the result.

An inline function imports src/smooth.ts, which loads this glTF model with three.js and welds its seams. The vitecache plugin runs it once in Node; a cache hit loads the geometry without importing GLTFLoader.

Checking the cache…

Neither the loader nor the inline function names the model's files: the plugin records what the load used, the modules it ran and the .gltf and .bin files three.js fetched. Edit src/smooth.ts or replace public/models/knot.bin, then reload: the load computes again.
